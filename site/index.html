Features

Built for daily puzzle solvers.

A minimalist, native desktop loop puzzle that respects your focus and your theme.

🎨

Omarchy Themed

Monitors colors.toml and hot-reloads live as you switch desktop themes.

⏱

Arcade Scoring

Dynamic multiplier decays over time. Build streaks and set personal records across 4 difficulty tiers.

🖱

Fluid Controls

Drag-to-draw lines, right-click drag crosses, click '0' to auto-cross, or use full keyboard navigation.

💾

Pick Up Later

Quit anytime. Your game state and timer are automatically saved and ready to resume on next launch.

Input Guide

Keyboard & Mouse Controls.

Designed to be equally enjoyable with a high-precision mouse or pure keyboard flow.

Mouse & Pointer

  • Left Click / Drag Draw loop line segments along edges
  • Right Click / Drag Mark '×' cross on edges not in loop
  • Click Clue '0' Automatically crosses out all 4 edges
  • Click Satisfied Clue Crosses out remaining edges around cell

Keyboard Controls

  • Arrows / H J K L Move active edge cursor
  • Space / Return Toggle line on selected edge
  • X / Backspace Toggle '×' cross on selected edge
  • C / Delete Clear edge state
  • U / Ctrl+Z Undo previous move
  • P Pause or resume game timer
  • Esc Return to main menu (autosaves)
